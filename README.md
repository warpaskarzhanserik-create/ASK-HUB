# ASK (Ambition · Strategy · Knowledge) — личные мудборды, видео‑рефы, заметки и раскадровка

Однопользовательское веб‑приложение: Next.js 15 + Postgres (Neon) + Vercel Blob для файлов.

## Что внутри
- **Проекты** — у каждого свои рефы, заметки и раскадровка.
- **Мудборд** — сетка картинок/видео: загрузка файлов (кнопка, drag&drop, вставка из буфера) или ссылка (картинка, Vimeo, YouTube, Instagram, любой сайт с превью).
- **Видео‑рефы** — Vimeo / Instagram / YouTube по ссылке со встроенным плеером, плюс свои видео‑файлы. К каждому рефу можно написать заметку.
- **Заметки** — Markdown, автосохранение, картинки вставляются из буфера.
- **Раскадровка** — карточки кадров: картинка, сцена, крупность, длительность, действие, камера, звук. Порядок меняется стрелками, есть печать/PDF.

Вход без пароля: сайт открыт всем, у кого есть ссылка.

## Переменные окружения
См. `.env.example`:

| Переменная | Что это |
|---|---|
| `DATABASE_URL` | строка подключения Postgres (Neon) |
| `BLOB_READ_WRITE_TOKEN` | токен Vercel Blob (на Vercel добавляется сам при подключении Blob) |

Таблицы в базе создаются автоматически при первом запросе.

## Запуск локально
```bash
npm install
cp .env.example .env.local   # заполнить значения
npm run dev                  # http://localhost:3000
```
Загрузка файлов локально работает, только если в `.env.local` есть `BLOB_READ_WRITE_TOKEN`
(ссылки и всё остальное работают и без него).

## Деплой на Vercel
1. Импортировать репозиторий на vercel.com → New Project.
2. Storage → Create → **Neon (Postgres)** → подключить к проекту (добавит `DATABASE_URL`).
3. Storage → Create → **Blob** → подключить к проекту (добавит `BLOB_READ_WRITE_TOKEN`).
4. Redeploy. Дальше каждый push в `main` деплоится сам.
